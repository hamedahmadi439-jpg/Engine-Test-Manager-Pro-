# Engine Test Manager Pro 2.2
مبنای این نسخه فایل کامل‌تر main(1).dart است و قابلیت‌های قبلی آن حفظ شده‌اند.

## پنج تغییر
1. Setup.exe با میانبر دسکتاپ و Start Menu و امکان Uninstall؛ در کنار خروجی portable ZIP.
2. فعال‌سازی Always on Top.
3. اعلان ویندوز هنگام ایجاد شیفت، ثبت موتور و جایگزینی/ویرایش رکورد.
4. بارکد تکراری با سه گزینه:
   - ثبت مجددا: افزودن ردیف جدید با همان بارکد.
   - ثبت ازنو: لغو عملیات و برگشت به فیلد اسکن.
   - جایگزینی با شماره قبلی: به‌روزرسانی نتیجه رکورد قبلی همان بارکد.
5. فیلد اسکن پس از ثبت دوباره فوکوس می‌گیرد تا بارکد بعدی بدون کلیک خوانده شود.
