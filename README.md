# Engine Test Manager Pro 2.1

نسخه توسعه‌یافته بر پایه سورس Flutter ویندوزی ارسالی.

## قابلیت‌های پیاده‌سازی‌شده
- ورود مدیر و اپراتور؛ رمز عبور به‌صورت هش SHA-256
- SQLite محلی و ذخیره اطلاعات در پوشه AppData ویندوز
- ساخت فرم شیفت با شماره سند، تاریخ و اپراتور
- ظرفیت ۸۰ موتور در هر فرم
- نمایش دو ستونه رکوردها
- ورود سریع بارکدخوان USB (در صورت عملکرد مانند کیبورد)
- وضعیت در انتظار، سالم، مردود و نیازمند بررسی
- ثبت ایراد و توضیحات
- هشدار شماره موتور تکراری و امکان ثبت مجدد با تأیید
- ویرایش، حذف و جابه‌جایی ردیف
- بستن فرم شیفت و قفل کردن ویرایش
- بایگانی و جست‌وجوی فرم‌ها
- مدیریت پایه کاربران و نقش‌ها
- تم مشکی، طلایی و آبی
- GitHub Actions برای ساخت ویندوز

## ورود اولیه
admin / admin123
پس از ورود، رمز مدیر را از مدیریت کاربران تغییر دهید.

## ساخت
flutter pub get
flutter analyze
flutter build windows --release

یا محتوای این پوشه را (به‌طوری‌که فایل pubspec.yaml و پوشه .github در ریشه مخزن باشند) در GitHub بارگذاری کنید. سپس از زبانه Actions، گردش‌کار Build Engine Test Manager Pro 2.1 (Windows) را اجرا کنید. این گردش‌کار پوشه Windows موردنیاز Flutter را خودش ایجاد می‌کند؛ نیازی به ساخت دستی آن نیست.

## محدودیت‌های فعلی
این سورس هنوز نسخه نهایی تمام امکانات توافق‌شده نیست. موارد زیر باید در مرحله بعد پیاده‌سازی و روی ویندوز آزمایش شوند:
- تقویم شمسی (ورودی فعلی میلادی است)
- خروجی و چاپ PDF و Excel
- پشتیبان‌گیری و بازیابی از داخل برنامه
- System Tray، پنجره شناور و اجرای خودکار با ویندوز
- گزارش‌های تحلیلی تفصیلی
- فیلتر مالکیت فرم‌ها برای اپراتورها
- ثبت لاگ فعالیت کاربران
- تقویت روش هش رمز با salt و KDF
- تست واقعی Windows 10 و بررسی امکان Windows 7

برنامه فقط نتایج واردشده را ثبت می‌کند و به استند تست موتور متصل نیست.
